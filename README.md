# 🌐 Oiyres CyberBrowser v1.0 [Core Edition]
> Легковесный, безопасный и настраиваемый веб-браузер, созданный на Python и PyQt6 (движок Chromium) для экосистемы **Oiyres Inc.**

---

## 🔥 Особенности
* 🚀 **Интеграция с движком Chromium**: Нативная поддержка HTML5, CSS3, JS, YouTube и высокая производительность веб-приложений.
* 🎨 **Hi-Tech / Киберпанк интерфейс**: Стильный темный дизайн, разработанный для максимальной концентрации и эстетики.
* 📑 **Многовкладочный интерфейс**: Поддержка открытия, закрытия и переключения неограниченного количества вкладок.
* 🔍 **Умная адресная строка**: Автоматическое распознавание поисковых запросов и веб-адресов.
* ⚡ **Быстрая ссылка на Oiyres Feedback Hub**: Доступ в один клик к локальной среде разработки (`http://localhost:2000`).
* 📦 **Автономный исполняемый файл**: Для запуска скомпилированного `.exe` файла не требуются внешние зависимости.

---

## 🛠️ Установка и использование

### Вариант 1: Запуск готового файла (Windows)
1. Перейдите в раздел [Релизы (Releases)](https://github.com).
2. Скачайте файл `OiyresCyberBrowser.exe`.
3. Запустите исполняемый файл.

### Вариант 2: Запуск из исходного кода
```bash
# Клонирование репозитория
git clone https://github.com/amiramusina2-beep/Oiyres-Browser.git
cd Oiyres-Browser

# Установка зависимостей
pip install PyQt6 PyQt6-WebEngine

# Запуск приложения
python oiyres_browser.py
```
